# F004 结果：关键事实笔记局部有效，但尚未超过 TopK

**日期：** 2026-08-13  
**状态：** `COMPLETE / DEVELOPMENT GATE NOT PASSED / F005 SEALED / F006 FEASIBILITY AUTHORISED`

## 1. 零基础结论

这次实验想回答两个问题：

1. Selector 删除干扰证据后，Generator 先把日期、地点、人名、数字等关键事实抄成小笔记，能不能少漏答案？
2. 再把 Selector 的 protect/harm 分数告诉 Generator，是否还能进一步变好？

答案是：

- **关键事实笔记有一点作用。** 相对当前 Selector 系统，109 题中多答对 4 题、改错 2 题，净增加 2 题；
- **Selector 风险分数没有额外作用。** G2 与 G1 总分相同，彼此是 2 题变好、2 题变坏；
- **整体仍没有超过 TopK。** G1 为 57.80%，同一 109 题的 TopK 高级组为 58.72%，仍少 1 题；
- 所以本轮不能宣布“完整系统已优于默认 TopK”，也不能进入最终盲测 F005。

这不是全盘失败。它把 Selector 路径相对 TopK 的差距从 F001 的 `−2.75 pp` 缩小到 `−0.92 pp`，而且证明了“先读关键事实”这条方向在真正启用时确实产生了净正向变化。

三组均为 0 个运行错误。G0 逐题复用 F001 冻结输出；G1/G2 在同一个作业共享同一 Granite 与 TRUE 模型实例。生成时没有加载 gold，gold 只在输出完成后评分。

## 4. 为什么仍说 G1 方向有价值

109 题中：

- G1 只在 37 题成功提取出非空关键事实笔记；
- 这 37 题相对 G0 从 21 题正确增加到 23 题，4 题改对、2 题改错，净增 2；
- 其余 72 题没有生成笔记，全部回退旧路径，答案逐字完全相同；
- 在这 37 个真正启用笔记的题上，G1 是 62.16%，TopK 是 59.46%，净多 1 题。

因此 +2 不是重复运行造成的随机差异，而是集中在笔记真正启用的题里。但这个 37 题子集是看到运行结果后定义的诊断子集，不能当成正式胜出证据；它只说明下一步应研究“怎样让可靠笔记覆盖更多合适题、同时减少改坏”，而不是继续堆 Selector 风险标签。
